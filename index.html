Highlights

We propose Parallel Instance Decoding

1

Efficiency gains

We predict the boxes of all instances in one parallel pass, so latency grows much more slowly with the number of objects in the scene.

22.4% Lower Latency on DIOR
43.6% Lower Latency on DOTAv2
2

Improved accuracy

Under the same data and training setup, PID improves F1@0.50 over the direct-box baseline by 8.3 points on DIOR and 7.3 points on DOTAv2.

Twice the small-object recall on DIOR Strong grounding and pointing
01

Point-addressed localization

We separate which object instances should be localized from where their boxes are placed. Given a textual reference, the model first generates a variable-length set of point addresses, one for each matching instance.

02

Instance-isolated attention

Each box attends to the full image, its reference and its own address, but not to the other boxes. All boxes are therefore independent and are predicted together in one parallel decoding pass.

03

One model for three tasks

A single model, built on LocateAnything-3B, predicts both the addresses and the boxes, and handles category-conditioned detection, referring-expression grounding and pointing.

04

Accuracy and efficiency

PID outperforms the direct-box baseline on DIOR and DOTAv2 while reducing complete-response latency, with the largest advantage in the denser DOTAv2 scenes. On DOTAv2 test images with little overlap with the training imagery, the accuracy gain is smaller.
